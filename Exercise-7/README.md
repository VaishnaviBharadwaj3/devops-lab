# Exercise 7: Introduction to Continuous Integration (CI) and Jenkins Installation

## Aim
To understand Continuous Integration (CI), its features and benefits, and install and access Jenkins using Docker.

## 1. Introduction to Continuous Integration (CI)
Continuous Integration is a software development practice in which developers frequently integrate code changes into a shared repository. Automated builds and tests help identify errors early and improve software quality.

## 2. Key Features of CI
- Frequent code integration
- Automated builds
- Automated testing
- Immediate feedback

## 3. Benefits of CI
- Early bug detection
- Improved collaboration
- Faster development cycles
- High-quality code

## 4. Introduction to Jenkins
Jenkins is an open-source automation server used to build, test, and deploy software. It supports Continuous Integration and Continuous Delivery.

### Key Jenkins Concepts
- **Job/Project:** A task Jenkins executes.
- **Build:** A run of a task or pipeline.
- **Pipeline:** A sequence of automated steps.
- **Plugins:** Extensions that add functionality.
- **Nodes:** Machines that execute Jenkins jobs.
